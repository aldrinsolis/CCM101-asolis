# Laboratory 05 - Cloud Data Engineer

## Mission Overview

This laboratory focuses on cloud storage concepts and the deployment of an object storage server. The mission uses Docker and MinIO to demonstrate how cloud-based object storage can be deployed and managed.

## Objectives

- Understand the three primary types of cloud storage.
- Compare Block Storage, File Storage, and Object Storage.
- Deploy a MinIO object storage server using Docker.
- Access the MinIO Web Console.
- Create an object storage bucket.
- Upload a sample file to the bucket.
- Document the deployment process using Markdown and GitHub.

## Tools Used

- KillerCoda Ubuntu Playground
- Docker
- MinIO
- GitHub
- Web Browser

## Skills Learned

- Comparing Block, File, and Object Storage.
- Running Docker containers.
- Deploying MinIO using Docker.
- Working with Docker port mapping.
- Using environment variables in Docker.
- Accessing a web-based storage console.
- Creating storage buckets.
- Uploading objects to a bucket.
- Documenting cloud infrastructure activities using Markdown and GitHub.
