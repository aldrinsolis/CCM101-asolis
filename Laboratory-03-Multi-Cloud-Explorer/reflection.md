# Mission Reflection

## 1. Which cloud platform impressed you the most?

The cloud platform that impressed me the most is **Amazon Web Services (AWS)**. I was impressed by the wide range of services available for computing, storage, networking, databases, security, and application development. AWS also provides flexible and scalable solutions that can support both small startups and large organizations.

## 2. What similarities exist among AWS, Azure, and GCP?

AWS, Microsoft Azure, and Google Cloud Platform (GCP) all provide similar fundamental cloud services. All three platforms offer virtual machines, object storage, databases, networking, identity management, and Kubernetes services. They also provide scalable infrastructure, global regions, security features, and management consoles that allow users to manage cloud resources.

## 3. How do business requirements influence cloud platform selection?

Business requirements are important when selecting a cloud provider because every organization has different needs, budgets, technologies, and goals. For example, a company using Microsoft technologies may benefit more from Azure, while an AI-focused company may prefer GCP. A startup or global business may choose AWS because of its broad range of services and scalability.

## 4. What did you learn from acting as a Cloud Solutions Consultant?

Acting as a Cloud Solutions Consultant taught me how to analyze business requirements and match them with appropriate cloud services. I learned that choosing a cloud provider is not simply about selecting the most popular platform. It requires understanding the organization's existing technology, budget, workload, scalability, performance, security, and future requirements.

My GitHub Cloud Computing Portfolio improved because I added organized research, comparison tables, client recommendations, decision matrices, and Linux investigation results. I also learned how to document technical information using Markdown and include screenshots as evidence of my work. This mission made my portfolio more complete and demonstrates my understanding of cloud computing concepts and cloud infrastructure.
