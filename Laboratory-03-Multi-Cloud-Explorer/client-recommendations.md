# Cloud Platform Recommendation Challenge

CloudNova Technologies has received requests from four different clients. Each client has different technical requirements, so the recommended cloud platform is based on budget, existing technologies, performance requirements, scalability, and global availability.

---

## Client A – Startup Company

### Recommended Cloud Platform: Amazon Web Services (AWS)

AWS is recommended for the startup because it provides a wide range of cloud services that can support a mobile application from development to production. AWS offers flexible and scalable services that allow the startup to begin with a small infrastructure and increase resources as the application gains more users. Its pay-as-you-go pricing model can also help the company manage its limited budget. AWS also provides many tools for application development, databases, storage, security, and monitoring.

### 3 Cloud Services

- **Amazon EC2** – Provides virtual servers for running application workloads.
- **Amazon S3** – Provides scalable storage for application files, images, and other data.
- **Amazon RDS** – Provides managed relational databases for storing application data.

---

## Client B – University

### Recommended Cloud Platform: Microsoft Azure

Microsoft Azure is the most appropriate platform for the university because it already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft's existing technologies, making cloud migration easier to manage. The university can use Microsoft Entra ID to manage identities and access while connecting its existing infrastructure with Azure services. Azure can also support hybrid cloud environments, allowing the university to gradually migrate services instead of moving everything at once.

### 3 Cloud Services

- **Azure Virtual Machines** – Provides cloud-based virtual machines for Windows Server workloads.
- **Microsoft Entra ID** – Provides identity and access management and integrates with Microsoft's ecosystem.
- **Azure Virtual Network** – Provides secure networking between Azure resources and existing university infrastructure.

---

## Client C – AI Research Company

### Recommended Cloud Platform: Google Cloud Platform (GCP)

Google Cloud Platform is recommended for the AI research company because it has strong capabilities in artificial intelligence, machine learning, data analytics, and high-performance computing. Google Cloud provides specialized infrastructure and services that can support demanding AI and ML workloads. Vertex AI provides tools for developing, training, and deploying machine learning models. The company can also use powerful compute resources to process large datasets and run computationally intensive workloads.

### 3 Cloud Services

- **Vertex AI** – Provides tools for building, training, and deploying AI and machine learning models.
- **Google Compute Engine** – Provides scalable virtual machines for high-performance workloads.
- **Google Cloud Storage** – Provides scalable storage for large datasets, training data, and research files.

---

## Client D – Global E-Commerce Company

### Recommended Cloud Platform: Amazon Web Services (AWS)

AWS is recommended for the global e-commerce company because it provides a large worldwide infrastructure and services designed for highly available and scalable applications. The company can deploy its application across multiple Availability Zones and geographic Regions to improve reliability and availability. AWS Auto Scaling can automatically adjust computing resources based on application demand. AWS also provides networking, database, storage, and content delivery services that can support a large global online shopping platform.

### 3 Cloud Services

- **Amazon EC2 Auto Scaling** – Automatically adjusts the number of computing resources based on demand.
- **Amazon RDS** – Provides managed relational database services for storing customer and transaction data.
- **Amazon CloudFront** – Provides content delivery to users around the world with reduced latency.
