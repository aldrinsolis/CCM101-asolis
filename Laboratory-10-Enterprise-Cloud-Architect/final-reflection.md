# Final Reflection - Laboratory 10: The Enterprise Cloud Architect

This final laboratory activity was a great experience for me because I was able to apply the knowledge and skills I learned from Laboratory Activities 1 to 9. Throughout this activity, I learned how to plan and manage a cloud infrastructure using Ubuntu Server, VirtualBox, Docker, and Docker Compose. I also understood how Ghost and MySQL work together to create a multi-tier application.

One of the most important things I learned was the importance of security in managing a server. Using the UFW firewall helped me understand why we need to control incoming connections and allow only the ports needed by the application. I also learned that persistent volumes are important because they help keep application and database data even when containers are restarted.

Another part of this activity was creating a Bash script for database backups and scheduling it using cron. This helped me understand how automation can make server maintenance easier and reduce the need to perform repetitive tasks manually. I also learned that backups are important because they can help recover data when unexpected problems happen.

During the course, I encountered different challenges while learning Linux commands, configuring containers, and managing server settings. These activities taught me to be more patient, careful, and willing to learn from my mistakes. I realized that building a working system requires proper planning, testing, and documentation.

Overall, this final mission helped me understand the responsibilities of an Enterprise Cloud Architect. I learned that deploying an application is not enough because we also need to consider security, data protection, automation, and recovery. From the first laboratory activity to the last, I gained more confidence in using cloud computing tools and managing a server environment. I believe the knowledge I gained from this course will help me in my future studies and career in Information Technology.
