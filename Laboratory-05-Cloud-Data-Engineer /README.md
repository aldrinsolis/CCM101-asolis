# Laboratory 05 - Cloud Data Engineer

## Mission Overview

In this laboratory activity, I learned about different types of cloud storage and deployed an object storage server using MinIO and Docker. I created a MinIO storage server, accessed its web console, created a bucket, and uploaded a sample file.

## Objectives

- Understand the three primary types of cloud storage.
- Compare Block Storage, File Storage, and Object Storage.
- Deploy MinIO using Docker.
- Access the MinIO Web Console.
- Create and manage an object storage bucket.
- Upload a sample file to the bucket.
- Document the technical deployment process.

## Tools Used

- KillerCoda Ubuntu Playground
- Ubuntu Linux
- Docker
- MinIO
- GitHub
- Web Browser

## Skills Learned

- Comparing different cloud storage types.
- Running Docker containers using the Linux command line.
- Deploying an S3-compatible object storage server.
- Configuring Docker environment variables.
- Mapping container ports.
- Creating and managing MinIO buckets.
- Uploading files to object storage.
- Documenting cloud infrastructure deployment.
- Organizing and maintaining a GitHub cloud computing portfolio.
