# Laboratory 05 - Cloud Data Engineer

## Mission Overview

In this laboratory activity, I explored different types of cloud storage and learned how object storage can be used to store large amounts of data. I researched Block Storage, File Storage, and Object Storage, then deployed a MinIO object storage server using Docker on a KillerCoda Ubuntu Playground. I also accessed the MinIO Web Console, created a bucket named `client-photos`, and uploaded a sample file.

## Objectives

- Understand the three primary types of cloud storage.
- Compare Block Storage, File Storage, and Object Storage.
- Learn how object storage is used for storing images and other unstructured data.
- Deploy a MinIO object storage server using Docker.
- Configure MinIO using Docker environment variables.
- Access the MinIO Web Console using port `9001`.
- Create and manage a storage bucket.
- Upload a sample file to the `client-photos` bucket.
- Document the deployment process using Markdown.
- Organize and update my cloud computing portfolio in GitHub.

## Tools Used

- **KillerCoda Ubuntu Playground** - Used as the Linux cloud environment.
- **Ubuntu Linux** - Used to run commands and manage the environment.
- **Docker** - Used to deploy and run the MinIO container.
- **MinIO** - Used as the S3-compatible object storage server.
- **GitHub** - Used to store and document the laboratory files.
- **Web Browser** - Used to access the MinIO Web Console.

## Skills Learned

- Understanding different types of cloud storage.
- Comparing Block, File, and Object Storage.
- Using Linux command-line commands.
- Running Docker containers.
- Deploying MinIO using Docker.
- Configuring Docker environment variables.
- Mapping container ports.
- Accessing a web-based storage console.
