
| Component | AWS | Microsoft Azure |
|---|---|---|
| Compute | Amazon EC2 – provides resizable virtual computing capacity. | Azure Virtual Machines – provides scalable virtual machines for Linux and Windows workloads. |
| Storage | Amazon S3 – object storage for storing and protecting data. | Azure Blob Storage – object storage optimized for large amounts of unstructured data. |
| Networking | Amazon VPC – provides logically isolated virtual networks. | Azure Virtual Network (VNet) – provides private networking. |
| Identity and Access Management | AWS IAM – controls authentication and permissions. | Microsoft Entra ID – manages identities and access. |
1. Which cloud provider offers the broadest range of services?

AWS offers one of the broadest ranges of cloud services and has a large portfolio covering computing, storage, databases, networking, security, analytics, AI, and many other areas. Its extensive service catalog makes it suitable for organizations with different types of cloud requirements.

2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

I would recommend Microsoft Azure because it integrates closely with Microsoft's products and technologies. Organizations already using services such as Microsoft 365, Windows Server, Active Directory, and other Microsoft technologies can benefit from Azure's integration and identity-management capabilities.

3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?

Google Cloud is widely recognized for its strengths in Artificial Intelligence and Machine Learning, while Google Kubernetes Engine (GKE) is a major Kubernetes service. AWS and Azure also provide strong AI, ML, and Kubernetes services, so the best choice depends on an organization's specific requirements.

4. What similarities did you observe among the three cloud providers?

All three cloud providers offer equivalent core infrastructure services for compute, storage, networking, and identity and access management. They also provide scalable, on-demand cloud resources and support security, monitoring, databases, AI, and other advanced cloud services.
