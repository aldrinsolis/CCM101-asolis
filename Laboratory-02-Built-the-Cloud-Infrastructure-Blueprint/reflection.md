1. Which cloud infrastructure component do you think is the most important? Why?

I think that network is the most important component of cloud infrastructure as it connects users, applications, servers and storage resources. A dependable network ensures cloud resources communicate with one another and enables users to access applications via the web. A network configured properly also helps protect cloud resources by controlling access to the resources by users and services.

3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it gives a clear plan for the infrastructure before deploying it. It tells you what resources are needed, what they do and how they are connected. Good documentation helps to avoid configuration mistakes and makes troubleshooting easier. It also makes it easier for other team members to understand and maintain the infrastructure.
