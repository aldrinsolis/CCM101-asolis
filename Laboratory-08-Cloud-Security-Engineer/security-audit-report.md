
# Security Audit Report

## 1. Principle of Least Privilege (PoLP)

The Principle of Least Privilege means giving each user or application only the permissions needed to perform its assigned tasks. This is important in cloud environments because it limits the damage that can happen if an account is compromised or a user makes a mistake.

## 2. Attack Surface

An attack surface is the collection of entry points that an attacker could try to exploit on a virtual machine. Examples include open network ports, exposed applications, outdated software, and accounts with weak credentials.

## 3. Default Deny Policy

A Default Deny policy blocks incoming network traffic unless a specific rule allows it. This is safer than trying to block individual hackers because unknown or new sources are also blocked unless they have permission to connect.
