
# Automation Research

## 1. Bash Script

A Bash script is a text file containing Linux commands that run in sequence to automate tasks. The `#!/bin/bash` line, called the shebang, tells the operating system to use the Bash interpreter when executing the script directly.

## 2. Variables

Variables store values such as folder paths, filenames, and timestamps so they can be reused throughout a script. For example, `$BACKUP_DIR` makes it easier to change the backup location in one place instead of editing every command that uses the same path.

## 3. Cron Job

A cron job is a scheduled task in Linux that runs a command or script automatically at a specified time or interval. It is useful in cloud operations because it can automate recurring tasks such as backups, log cleanup, and maintenance without requiring someone to run them manually.
